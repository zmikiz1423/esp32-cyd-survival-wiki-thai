เตรียมแผนที่ประเทศไทยลง SD Card

เลือกพื้นที่ครั้งเดียว แล้วอ่านแผนที่บนบอร์ดและโทรศัพท์ได้โดยไม่ใช้อินเทอร์เน็ต
ขั้นที่ 1 · เลือกพื้นที่

จะนำแผนที่ไปใช้ที่ไหน?

มีจุดเริ่มต้นโดยประมาณครบ 77 จังหวัด และเมืองท่องเที่ยว เลือกสถานที่จริงด้วยการค้นหาหรือพิกัดด้านล่างได้
คัดลอกตัวเลขพิกัดจากแอปแผนที่มาวางได้ จุดที่เลือกเป็นศูนย์กลางของพื้นที่สี่เหลี่ยม
กำลังคำนวณ...

ซูม 15–16 ขยายข้อมูลถนนที่มีอยู่ ไม่ได้เพิ่มข้อมูลใหม่ทุกระดับ แผนที่นี้แสดงถนน ทางเดิน น้ำ พื้นที่สีเขียว และชื่อสถานที่ ไม่ใช่แผนที่เส้นชั้นความสูงหรือระบบนำทางเลี้ยวต่อเลี้ยว

ขั้นที่ 2 · เลือกที่บันทึก

เลือกไดรฟ์ SD เช่น E:\ ได้เลย โปรแกรมจัดโฟลเดอร์ maps ให้ หรือบันทึกในคอมพิวเตอร์ก่อนแล้วคัดลอก maps ลงราก SD ภายหลัง

ขั้นที่ 3 · ดาวน์โหลด

ตรวจแผนที่ก่อนบันทึก

กดตรวจพื้นที่เพื่อดูตัวอย่างจากข้อมูลจริง
ครั้งละไม่เกิน 3,000 แผ่น และข้อมูลดาวน์โหลดจากแหล่งแผนที่ไม่เกิน 50 MB โปรแกรมควบคุมขนาดให้อัตโนมัติ

ใช้อินเทอร์เน็ตเฉพาะตอนเตรียมแผนที่บนคอมพิวเตอร์ ไม่มีค่าสมัครหรือ API key แหล่งข้อมูลอาจไม่ครอบคลุมถนนหรือทางเดินทุกเส้น

กำลังเปิดเครื่องมือ...
นำไปใช้งานบนบอร์ด
  1. ใช้ microSD แบบ FAT32 และเก็บ wiki, library, web เดิมไว้
  2. เมื่อดาวน์โหลดครบ ต้องมี maps/center.txt และโฟลเดอร์ตัวเลขอยู่ที่รากการ์ด
  3. ถอดการ์ดอย่างปลอดภัย ใส่บอร์ด แล้วรีเซต เปิดเมนู “แผนที่”
  4. ลากเพื่อเลื่อน กด + / − เพื่อซูม กด “ฉัน” เมื่อมีพิกัด GPS หรืออ่านแผนที่ผ่าน http://192.168.4.1/map
ดาวน์โหลดค้าง หรือเห็นแผนที่ว่าง?

ถ้าหยุดกลางทาง ให้กดตรวจพื้นที่และดาวน์โหลดอีกครั้งด้วยจุด/ระยะ/ซูม/โฟลเดอร์เดิม แผ่นที่บันทึกแล้วจะไม่ถูกโหลดซ้ำ โปรแกรมปรับจุดเริ่มต้นใน center.txt เมื่อครบทุกแผ่นแล้วเท่านั้น หากเกินขนาด ให้เลือกพื้นที่เล็กลงหรือซูมแบบภาพรวม

นอกพื้นที่หรือระดับซูมที่บันทึกไว้จะแสดงพื้นว่าง หากโฟลเดอร์มีแผนที่จากแหล่งเดิม โปรแกรมอาจให้เลือกโฟลเดอร์ใหม่ เพื่อไม่ปะปนกับข้อมูลคนละชุด เก็บ waypoints.txt และ track.csv ของคุณไว้เสมอ
