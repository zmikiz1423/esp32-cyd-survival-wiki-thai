# การแปลวิกิภาษาไทย

แปลบทความครบ 118 บทความใน `sdcard/wiki/articles/` พร้อมชื่อเรื่อง คำอธิบายผลค้นหา ชื่อหมวดหมู่ และแค็ตตาล็อกทั้ง 118 รายการ เนื้อหาฉบับสุดท้ายผ่านการเขียนและปรับสำนวนภาษาไทยโดยเทียบต้นฉบับทุกบทความ ไม่ได้ใช้ร่างแปลอัตโนมัติโดยตรง

รักษารหัสบทความ รหัสหมวดหมู่ ลำดับรายการ ชื่อไฟล์ ลิงก์ภายใน และตำแหน่งภาพเดิมไว้ คำค้นใน front matter บางส่วนเก็บภาษาอังกฤษเดิมควบคู่กับภาษาไทย เพื่อให้ยังค้นด้วยคำเดิม เช่น CPR, AED หรือชื่อยาภาษาอังกฤษได้ คำเหล่านี้ไม่ใช่ข้อความเนื้อหาที่ยังแปลไม่เสร็จ

เนื้อหาเป็นคำแปลตามต้นฉบับ รวมบริบทอเมริกาเหนือของความถี่วิทยุ ใบอนุญาต เบอร์ฉุกเฉิน และการจราจร ไม่ได้เปลี่ยนเป็นข้อกำหนดของประเทศไทย คำสั่งรักษาหรือปฐมพยาบาลคงตามต้นฉบับ การตรวจคำแปลไม่ใช่การรับรองทางการแพทย์หรือการปรับคู่มือให้เป็นแนวทางรักษาฉบับปัจจุบัน

ผลตรวจด้วย `python scripts/verify_wiki_thai.py`:

- บทความและแค็ตตาล็อกครบ 118 รายการ ไม่มีรหัสซ้ำหรือรายการสูญหาย
- ค่าตัวเลขต้นฉบับในเนื้อหา 930 ตำแหน่งยังอยู่ครบ
- ปลายทางลิงก์และภาพ 156 ตำแหน่งตรงต้นฉบับและมีไฟล์ครบ
- ชื่อเรื่อง คำอธิบาย และเนื้อหาทุกบทความมีภาษาไทย
- ไม่พบอักขระเสียหายหรือ placeholder จากกระบวนการแปล
- บทความยาวที่สุด 7,061 ไบต์ ก่อนเพิ่มข้อมูลตัดคำสำหรับหน้าจอ

ต้นฉบับสำรองและผลตรวจเชิงโครงสร้างอยู่ใน `.thai-work/original/sdcard/wiki/` และ `.thai-work/wiki-verification.json` สคริปต์ `translate_wiki.py` ใช้สร้างร่างเท่านั้น ไม่ควรรันหลังแก้สำนวน เพราะจะเขียนทับฉบับภาษาไทยที่ตรวจแล้ว สคริปต์ `polish_thai_wiki.py`, `thai_wiki_extra.py`, `thai_wiki_hazards.py` และ `thai_wiki_summaries.py` เก็บข้อความที่เขียนและตรวจสำนวนไว้ 86 บทความ อีก 32 บทความอยู่ในไฟล์บทความฉบับสุดท้ายโดยตรง

ไฟล์ค้นหา หนังสือรวมบทความ PDF และแพ็กเกจ SD Card ต้องสร้างใหม่จากบทความฉบับสุดท้าย จึงจะได้ภาษาไทยตรงกันทุกช่องทาง
