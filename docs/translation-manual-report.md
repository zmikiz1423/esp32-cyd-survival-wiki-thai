# รายงานการแปลคู่มือ FM 21-76

แปลไฟล์ข้อความ `sdcard/library/fm21-76/0001.txt` ถึง `0062.txt` เป็นภาษาไทยครบทั้ง 62 ส่วน โดยคงชื่อไฟล์และลำดับส่วนเดิม เพื่อให้สารบัญและโปรแกรมอ่านหนังสือเดิมใช้งานต่อได้

ต้นฉบับภาษาอังกฤษมีขนาด 531,775 ไบต์ แบ่งเป็นช่วงข้อความสำหรับแปล 2,557 ช่วง สร้างร่างด้วยบริการแปลอัตโนมัติ แล้วตรวจแก้ศัพท์การเอาชีวิตรอด การแพทย์ ภูมิประเทศ การจับสัตว์ และอันตรายนิวเคลียร์หรือสารชีวภาพ ใช้คำศัพท์เฉพาะที่ป้องกันการแปลผิดมากกว่า 170 รายการ แก้หัวข้อหรือคำแนะนำสั้นด้วยข้อความที่เขียนเอง 401 แห่ง และเขียนคำแปลย่อหน้าใหม่สำหรับส่วนที่พบความหมายคลาดเคลื่อน

การตรวจภาษาในรอบนี้ครอบคลุมหัวข้อ คำเตือน ตัวอย่างข้อความในทุกส่วน และการค้นหาคำกำกวมทั้งชุด เช่น still, game, dressing, canteen, stake, spit, digital pressure, agent และ fallout ไม่ใช่การตรวจทุกคำทั้งเล่มโดยผู้เชี่ยวชาญด้านการแพทย์หรือผู้เชี่ยวชาญทุกสาขา จึงไม่ควรเรียกฉบับนี้ว่าเป็นคู่มือที่ผ่านการรับรองทางการแพทย์

## การตรวจไฟล์

ใช้ `scripts/verify_manual_translation.py` ตรวจทุกส่วนว่าเป็น UTF-8 ไม่มีอักขระเสีย ไม่มีเครื่องหมายกำกับการแปลหลงเหลือ มีภาษาไทย และมีขนาดไม่เกิน `MAX_DOC_BYTES` ของเฟิร์มแวร์ ตรวจด้วยว่าตัวเลขทุกชุดจากต้นฉบับยังปรากฏครบในคำแปล ตัวเลขที่เพิ่มขึ้นบางแห่งมาจากการแปลงคำภาษาอังกฤษ เช่น two เป็น 2

ระหว่างแปล ตรวจเครื่องหมายกำกับทุกช่วงข้อความเพื่อยืนยันว่ามีผลแปลครบและเรียงตามต้นฉบับ หากบริการแปลทำเครื่องหมายหรือศัพท์ที่ป้องกันไว้หาย โปรแกรมจะไม่ยอมรับผลนั้น และจะลองแปลแยกเป็นย่อหน้าแทน

ผลตรวจรายละเอียดและขนาดไฟล์ล่าสุดอยู่ใน `.thai-work/manual-verification.json` ต้นฉบับเก็บไว้ใน `.thai-work/original/library/fm21-76/` และผลแปลชั่วคราวเก็บใน `.thai-work/translate-cache/` ข้อมูลเหล่านี้ไม่ต้องคัดลอกลง SD Card

หากต้องสร้างคำแปลใหม่ ให้ใช้ `scripts/translate_manual.py` ร่วมกับต้นฉบับที่เก็บไว้ และไฟล์แก้ภาษา `scripts/manual_thai_edits.tsv` กับ `scripts/manual_thai_paragraphs.tsv` โปรแกรมนี้เขียนทับไฟล์คู่มือที่แปลแล้ว จึงควรสำรองการแก้ไขเพิ่มเติมก่อนใช้งาน

## สถานะของต้นฉบับ

FM 21-76 เป็นคู่มือประวัติศาสตร์ของกองทัพสหรัฐฯ ฉบับปี 1992 การแปลรักษาคำแนะนำจากต้นฉบับ ซึ่งรวมถึงวิธีรักษาเก่าบางอย่าง เช่น การดูดพิษงู การจำกัดน้ำขณะท้องเสีย และการกินน้ำมันก๊าดหรือยาสูบกำจัดพยาธิ วิธีเหล่านี้ไม่ควรถูกนำเสนอว่าเป็นคำแนะนำการแพทย์ปัจจุบัน การเก็บไว้มีวัตถุประสงค์เพื่อรักษาเนื้อหาของเอกสารต้นฉบับ ผู้ใช้ควรแยกคู่มือประวัติศาสตร์นี้ออกจากแนวทางปฐมพยาบาลปัจจุบัน
