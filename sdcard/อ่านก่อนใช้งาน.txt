ชุด SD Card ภาษาไทยสำหรับ ESP32 CYD Survival Wiki 1.6.0-th4

คัดลอกสิ่งที่อยู่ภายในโฟลเดอร์ sdcard หรือแตก sdcard-TH.zip ลงที่ราก microSD
ที่ฟอร์แมตเป็น FAT32 ต้องเห็น config.txt, wiki, library และ web ที่รากการ์ด
ใช้คู่กับ firmware-CYD28.bin ซึ่งเป็น image รวมสำหรับแฟลชที่ 0x0

ชื่อ Wi-Fi เริ่มต้น: SurvivalWiki
เปิดอ่านจากโทรศัพท์ที่ http://192.168.4.1 หลังเชื่อมต่อ Wi-Fi ของอุปกรณ์
หากใช้การ์ดเดิม ให้เก็บ maps, config.txt และไฟล์สำรองการตั้งค่าของคุณไว้

บทความ 118 เรื่อง พร้อมภาพประกอบไทย 22 ภาพ และหนังสือรวม 22 ตอน
FM 21-76 แปลไทยครบ 62 ส่วน ส่วน PDF มีภาคผนวกต้นฉบับอังกฤษครบ 233 หน้า
เพื่อรักษาภาพและตารางสำหรับอ้างอิง

FM 21-76 เป็นเอกสารประวัติศาสตร์ปี 1992 มีวิธีรักษาที่ล้าสมัยหรืออันตราย
คำแปลใช้ระบบแปลร่วมกับการเกลาศัพท์และแก้ข้อความ ยังไม่ผ่านผู้เชี่ยวชาญตรวจทุกบรรทัด
อย่าใช้เอกสารเก่าเป็นคำแนะนำรักษาพยาบาลปัจจุบัน

รายละเอียดการติดตั้ง การคอมไพล์ และข้อจำกัดอยู่ใน README_TH.md ของโปรเจ็กต์

แผนที่ประเทศไทย: เปิด ดาวน์โหลดแผนที่ไทย.bat ที่โฟลเดอร์โปรเจ็กต์ หรือแตก
Thailand-Map-Downloader.zip แล้วเปิดไฟล์เดียวกัน เลือกพื้นที่และเลือก SD ในหน้าเว็บ
ไม่ต้องติดตั้ง Python หรือ Node.js และไม่ต้องสมัคร API key
ดูขั้นตอนทั้งหมดใน MAPS_TH.md หรือคู่มือแผนที่ไทย.txt ในชุด SD

แผนที่ทั้งจังหวัด: ใช้ เตรียมแผนที่ทั้งจังหวัด.bat ในชุด Thailand-Offline-Province-Maps.zip
เลือกจังหวัดและระดับซูม กดครั้งเดียวแล้วรอเสร็จครบ ดู คู่มือแผนที่ออฟไลน์ทั้งจังหวัด.txt

ชุด SD th3 รวมแผนที่สุราษฎร์ธานีทั้งจังหวัด ซูม 8–16 จำนวน 55,125 ภาพ
หากใช้การ์ดเดิม ให้สำรองและเปลี่ยนชื่อ maps เดิมก่อนใส่ชุดใหม่ อย่าคัดลอกทับรวมภาพต่างชุด

โครงการต้นฉบับ: https://github.com/everyday3d/esp32-cyd-survival-wiki
ขอขอบคุณ Everyday3D / BoxerDawg 3D และผู้ร่วมพัฒนา ดูใบอนุญาตต้นฉบับใน LICENSE.txt

หลายจังหวัดใน SD Card (เฟิร์มแวร์ th4 ขึ้นไป):
เก็บ maps เดิมไว้ได้ เพิ่มแต่ละจังหวัดเป็น maps-chumphon, maps-krabi ฯลฯ ที่ราก SD
เปลี่ยนชื่อเฉพาะโฟลเดอร์ชั้นนอก ไม่เปลี่ยนชื่อ center.txt หรือโฟลเดอร์ตัวเลขข้างใน
อาจใส่ name.txt แบบ UTF-8 บรรทัดแรกเป็นชื่อไทย เช่น ชุมพร เพื่อใช้แสดงในเมนู
เปิด แผนที่ → จังหวัด บน CYD แล้วเลือกชุด ระบบจำชุดที่เลือกเมื่อเปิดเครื่องใหม่
ไม่กำหนดจำนวนชุดตายตัว แต่ต้องมีพื้นที่การ์ดพอ GPS ไม่สลับจังหวัดให้อัตโนมัติ
ปิดบอร์ดก่อนถอด SD และอย่าคัดลอกภาพต่างจังหวัดทับรวมในโฟลเดอร์เดียวกัน
การ์ด th3 ที่ใช้งานได้แล้วเพียงอัปเดตเฟิร์มแวร์ ไม่ต้องคัดลอกชุด SD ใหม่ทั้งหมด
ดูรายละเอียดใน MULTI_MAPS_TH.md ของโปรเจ็กต์
