# Survival Wiki ภาษาไทยสำหรับ CYD 2.8 นิ้ว

ฉบับภาษาไทยนี้พัฒนาต่อยอดจาก [esp32-cyd-survival-wiki โดย Everyday3D](https://github.com/everyday3d/esp32-cyd-survival-wiki) โดยผู้ดูแลฉบับภาษาไทยได้ขออนุญาตนำโครงการมาต่อยอดแล้ว ขอขอบคุณ Everyday3D / BoxerDawg 3D และผู้ร่วมพัฒนาโครงการต้นฉบับ ที่สร้างและแบ่งปันเครื่องมือออฟไลน์ที่เป็นประโยชน์ รวมถึงเปิดโอกาสให้พัฒนาเป็นเวอร์ชันภาษาไทยสำหรับผู้ใช้งานในประเทศไทย เราคงเครดิตและไฟล์ LICENSE ของโครงการต้นฉบับไว้

**รุ่น 1.6.0-th3:** เพิ่มตัวเตรียมแผนที่ออฟไลน์ทั้งจังหวัด กดครั้งเดียวแล้วสร้างภาพทุกพื้นที่ตามขอบเขตและช่วงซูมที่เลือก รวมเกาะ พร้อมโหมดติดตาม GPS และข้อมูลสถานที่ ใช้ `เตรียมแผนที่ทั้งจังหวัด.bat` ดู [คู่มือทั้งจังหวัด](OFFLINE_MAPS_TH.md) ชุดแยก `Thailand-Offline-Province-Maps.zip` มีตัวรัน Windows 64 บิตพร้อมใช้ ไม่ต้องติดตั้ง Python

ฉบับนี้ใช้กับ **ESP32-2432S028R / CYD 2.8 นิ้ว จอ ILI9341 ขนาด 240 × 320 พิกเซล และสัมผัสแบบตัวต้านทาน** โดยคงระบบอ่านบทความ/หนังสือ รูปภาพ Wi-Fi และ captive portal แชต ESP-NOW แผนที่ จุดบันทึก GPS เรดาร์ เครื่องมือโทรศัพท์ การประเมินเหตุ ไฟฉาย SOS การตั้งค่า การสำรองข้อมูล และคู่มือสุนัขจากโครงการเดิม

**รุ่น 1.6.0-th2 รองรับการเตรียมแผนที่ประเทศไทยแล้ว:** ดับเบิลคลิก `ดาวน์โหลดแผนที่ไทย.bat` เลือกพื้นที่และ SD Card ในหน้าเว็บภาษาไทย ไม่ต้องติดตั้ง Python/Node หรือใช้ API key ดู [คู่มือแผนที่ประเทศไทย](MAPS_TH.md) หากต้องการเฉพาะตัวช่วยดาวน์โหลด ใช้ `Thailand-Map-Downloader.zip` แล้วแตกไฟล์ทั้งหมดก่อนเปิด

ชุด SD รุ่น th3 มีแผนที่สุราษฎร์ธานีครบพื้นที่ตามขอบเขตและช่วงซูม 8–16 รวม 55,125 ภาพไว้แล้ว แยกเฉพาะแผนที่ใน `maps-Surat-Thani-offline.zip` ด้วย ให้สำรองและเปลี่ยนชื่อ `maps` เดิมก่อนนำชุดนี้ลง SD อย่ารวมภาพต่างชุดด้วยการคัดลอกทับ ส่วนตัวอย่างใจกลางกรุงเทพฯ จากรุ่นก่อนยังเก็บไว้ใน `maps-Bangkok-demo.zip`

## ติดตั้งเฟิร์มแวร์

ใช้ **`firmware-CYD28.bin` ที่โฟลเดอร์หลักของโปรเจ็กต์** เป็นไฟล์รวม bootloader, partition table, boot_app0 และแอปแล้ว ตั้งตำแหน่งแฟลชเป็น **`0x0`** ชิป **ESP32**, Flash **4 MB**, Mode **DIO**, Frequency **40 MHz**

ตัวอย่าง esptool (เปลี่ยน `COM5` ให้ตรงกับพอร์ตของบอร์ด):

```powershell
python -m pip install esptool==4.5.1
python -m esptool --chip esp32 --port COM5 --baud 460800 write_flash -z 0x0 firmware-CYD28.bin
```

ไฟล์นี้เป็น image รวม อย่านำไปแฟลชที่ `0x10000` ซึ่งเป็นตำแหน่งสำหรับไฟล์แอปอย่างเดียว เสียบสาย USB ที่ส่งข้อมูลได้ และรีเซตบอร์ดเมื่อแฟลชเสร็จ หากบอร์ดร้องขอการเทียบสัมผัส ให้แตะเครื่องหมายทีละจุด

ไฟล์ที่เส้นทางเดิม `firmware/bin/survival-wiki-28-full.bin`, `docs/firmware/survival-wiki-28-full.bin` และ `web-flasher/firmware/survival-wiki-28-full.bin` เป็นสำเนา image ภาษาไทยเดียวกัน เพื่อให้ตัวแฟลชเว็บภายในโปรเจ็กต์ยังใช้ได้

## เตรียม SD Card

1. ใช้ microSD ที่ฟอร์แมตเป็น FAT32
2. คัดลอก **สิ่งที่อยู่ภายใน `sdcard`** ไปที่รากการ์ด หรือแตก `sdcard-TH.zip` ลงรากการ์ดโดยตรง ต้องเห็น `config.txt`, `wiki`, `library`, `web` ที่ราก ไม่ใช่มีโฟลเดอร์ `sdcard` ครอบอีกชั้น
3. หากอัปเดตการ์ดเดิม ให้เก็บ `maps`, `config.txt`, ไฟล์สำรองการตั้งค่า และเส้นทาง/จุดบันทึกของคุณไว้
4. เปิดเครื่อง อ่านได้จากจอ หรือเชื่อมต่อ Wi-Fi ชื่อ `SurvivalWiki` แล้วเข้า `http://192.168.4.1`

บทความ 118 เรื่องและภาพประกอบ 22 ภาพเป็นภาษาไทย หนังสือฉบับรวมสร้างจากบทความชุดเดียวกัน ดัชนีค้นหาและไฟล์ `.gz` สร้างใหม่จากข้อมูลภาษาไทยแล้ว PDF รวมบทความมีภาพประกอบภาษาไทย ส่วน FM 21-76 มีข้อความแปลไทยครบ 62 ส่วน และภาคผนวกต้นฉบับภาษาอังกฤษครบ 233 หน้าเพื่อเก็บภาพ/ตารางเดิมไว้สำหรับอ้างอิง

FM 21-76 เป็นเอกสารปี **1992** มีแนวทางทางการแพทย์ที่ล้าสมัยหรืออันตราย จึงมีข้อความเตือนในทุกส่วนและใน PDF คำแปลคู่มือนี้ใช้ระบบแปลร่วมกับการเกลาศัพท์ การแก้ย่อหน้าที่คลาดเคลื่อน และการตรวจครบทุกไฟล์ ยังไม่ได้ผ่านผู้เชี่ยวชาญตรวจทุกบรรทัด อย่าใช้เอกสารประวัติศาสตร์เป็นแนวทางรักษาพยาบาลปัจจุบัน

## การแสดงภาษาไทย

- ใช้ **Sarabun** ภายใต้ SIL Open Font License 1.1 เก็บฟอนต์และใบอนุญาตไว้ใน `firmware/fonts` และ `sdcard/web`
- ใช้ **HarfBuzz + FreeType** ขณะสร้างข้อมูลฟอนต์ เพื่อจัดรูปอักษรและตำแหน่งสระ/วรรณยุกต์ตาม OpenType รวมทั้งอักษรหางสูง อักษรหางล่าง และสระอำ
- ฝังตารางอักษรและบิตแมปในแฟลช ใช้ร่วมกับ **TFT_eSPI 2.5.43** ไม่ต้องใช้ PSRAM และเมนูยังเป็นภาษาไทยแม้ไม่เสียบ SD
- วัดความกว้างด้วยข้อมูลเดียวกับที่ใช้วาดจริง ตัดข้อความตามกลุ่มอักษร UTF-8 ไม่ตัดไบต์หรือแยกวรรณยุกต์จากพยัญชนะ บทความตัดคำด้วย PyThaiNLP ในขั้นตอนเตรียมไฟล์
- จอ CYD ใช้หน้าหลัก 6 ช่องต่อหน้าเพื่อให้มีพื้นที่สำหรับสระ/วรรณยุกต์ หมวดและฟังก์ชันเดิมยังอยู่ครบ ชื่อเรื่องยาวในแถบหัว/รายการแสดง `...` และอ่านชื่อเต็มได้ในเนื้อหา
- มีแป้นพิมพ์ไทย 4 หน้า พร้อมสลับอังกฤษ และลบเป็นกลุ่มอักษร
- แชตคงรูปแบบ packet เดิมเพื่อทำงานกับบอร์ดรุ่นเดิมได้: ข้อความไม่เกิน **63 ไบต์ UTF-8** ชื่อไม่เกิน **11 ไบต์** หน้าเว็บแจ้งเมื่อเกินขนาดและเก็บข้อความให้แก้ ไม่ตัดกลางอักษรไทย

การใช้ข้อความไทยผ่านเมชต้องอัปเดตบอร์ดผู้ส่ง ผู้รับ และบอร์ดที่ส่งต่อข้อความเป็นฉบับไทยทั้งหมด เพราะเฟิร์มแวร์อังกฤษเดิมแปลงอักษรนอก ASCII เป็น `?` ข้อความอังกฤษยังใช้รูปแบบ packet เดิมได้

## คอมไพล์และสร้างข้อมูลซ้ำ

ใช้ Python 3.11 ขึ้นไป:

```powershell
python -m pip install -r scripts/requirements-thai.txt
powershell -ExecutionPolicy Bypass -File scripts/build-cyd28.ps1
```

สคริปต์สร้าง image รวมชื่อ `firmware-CYD28.bin` และอัปเดตไฟล์สำหรับตัวแฟลชเว็บเดิม ค่าเริ่มต้นของ PlatformIO เป็น `survival-wiki-28` แล้ว แต่ยังคง environment ของจอ 3.5 นิ้วไว้

หากแก้บทความภาษาไทย ให้บันทึกเป็น UTF-8 แล้วสร้างเนื้อหาที่เกี่ยวข้องใหม่ตามลำดับ:

```powershell
python scripts/build_thai_sd.py
python scripts/build_thai_font.py
python scripts/verify_thai_render.py
python scripts/build_thai_pdfs.py
python scripts/package_thai_release.py
```

สคริปต์ `translate_*`, `polish_*`, `patch_thai_ui.py`, `apply_thai_ui_strings.py` และ `localize_web_thai.py` เป็นประวัติการย้าย/เกลาฉบับภาษาไทย ไม่ใช่ขั้นตอนคอมไพล์ตามปกติ อย่ารันสคริปต์แปลอัตโนมัติทับงานเกลาสำนวนโดยไม่ตรวจผลก่อน ข้อมูลต้นฉบับและแคชงานรอบนี้เก็บไว้ใน `.thai-work/original` และ `.thai-work` ของเครื่องนี้ ซึ่งไม่ได้อยู่ในชุด SD

## การตรวจสอบและข้อจำกัด

รายงานอยู่ใน `docs/thai-*-report.json` และรายงานการแปลใน `docs/translation-*-report.md` มีการเทียบตารางจัดอักษรกับ HarfBuzz ตรวจการครอบคลุมอักษรไทย/ความสูงบรรทัด/ความกว้าง 224 และ 206 พิกเซล ตรวจหน้าเว็บที่ความกว้าง 240, 320 และ 390 พิกเซล และคอมไพล์เป้าหมาย ESP32 จริง

**ยังไม่ได้แฟลชทดสอบบนบอร์ดจริงในงานนี้** การอ่านจอผ่าน SPI ความเร็วการวาด การสัมผัส Wi-Fi วิทยุ ESP-NOW และ GPS จึงยังต้องยืนยันบนฮาร์ดแวร์ ภาพ `docs/thai-render-preview.png` เป็นการตรวจจากตารางฟอนต์บนคอมพิวเตอร์ ไม่ใช่ภาพถ่ายจากบอร์ด

แหล่งอ้างอิงฟอนต์และการจัดอักษร: [Sarabun / Google Fonts](https://github.com/google/fonts/tree/main/ofl/sarabun), [HarfBuzz Thai/Lao shaping](https://harfbuzz.github.io/opentype-shaping-models.html) การระบุข้อควรระวังของเอกสารเก่าอ้างอิง [CDC: งูพิษ](https://www.cdc.gov/niosh/outdoor-workers/about/venomous-snakes.html) และ [WHO: โรคอุจจาระร่วง](https://www.who.int/health-topics/diarrhoea)
